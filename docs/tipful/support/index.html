Käufe wiederherstellen

Öffne in Tipful „Mehr → Käufe wiederherstellen“. Verwende dieselbe Apple-ID wie beim ursprünglichen Kauf.

Abonnement verwalten

Öffne „Mehr → Abonnement verwalten“. Kündigungen und Tarifverwaltung erfolgen direkt bei Apple.

Lokale Daten löschen

Unter „Mehr → Alle lokalen Daten löschen“ entfernst du Trinkgeldeinträge und Schichten dauerhaft vom Gerät. Käufe bleiben über deine Apple-ID wiederherstellbar.

Werbung melden

Sende uns möglichst Datum, Uhrzeit, eine Beschreibung und – sofern gefahrlos möglich – einen Screenshot. Tippe nicht erneut auf eine verdächtige Anzeige.
