2. Lokale Trinkgelddaten

Trinkgeldbeträge, Notizen, Schichten, Ziele und Einstellungen werden ausschließlich lokal auf dem verwendeten Gerät gespeichert. Tipful betreibt hierfür kein Benutzerkonto und überträgt diese Inhalte nicht an einen eigenen Server. Unter „Mehr → Alle lokalen Daten löschen“ können diese Daten jederzeit vom Gerät entfernt werden. Eine Deinstallation löscht die lokalen App-Daten ebenfalls entsprechend den Regeln des Betriebssystems.
